📋 Cara Menggunakan

1. Masukkan URL website dan informasi aplikasi di tab Build APK.
2. Sesuaikan konfigurasi di tab Konfigurasi (opsional).
3. Klik tombol "Generate APK" dan tunggu proses selesai.
4. Download file APK dan install di perangkat Android kamu.

Catatan: Untuk production/Play Store, gunakan keystore yang valid dan proses penandatanganan APK secara manual.
